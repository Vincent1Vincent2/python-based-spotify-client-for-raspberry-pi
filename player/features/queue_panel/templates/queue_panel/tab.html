Queue

New items go to the end of the queue. Add to Queue on a song still uses that existing control and appends there. Spotify's public API cannot remove a queued item, reorder the queue, or insert one at the front. This list is the current item plus the upcoming items Spotify returns. That read is not paged and stops after the items Spotify includes (about 20). This screen does not skip tracks to read further.
